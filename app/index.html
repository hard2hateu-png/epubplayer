Pocket TTS 3

English · voice cloning · runs on this server

Voice cloning uses Kyutai's Pocket TTS 3 model, which is freely available on Hugging Face behind a terms-acceptance gate. One-time setup:

  1. Create a free Hugging Face account (if you don't have one)
  2. Open the model page and accept the terms
  3. Create a token at Settings → Access tokens (a read token is enough) and paste it below

A token you enter here is saved in this browser and sent securely to the speech server to download the model. It is not saved by the app on the server. Until then, built-in voices are available below.
