Chatterbox Nano on iPhone

This page does not touch the EPUB reader or register a new TTS engine. It only tests whether the smaller Chatterbox Nano ONNX model can load, condition on Leo, and survive repeated local generations on this device.

The first model load is large: roughly 547 MiB of published Nano files. Keep Safari in the foreground and preferably use Wi‑Fi. The default backend is single-threaded WASM because current ONNX Runtime Web does not officially support WebGPU on Safari/iOS.
